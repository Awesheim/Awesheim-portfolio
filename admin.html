How saving works

This is a static site with no server, so this page cannot write files by itself. Edit here, then export and commit the two files it gives you:

  • content.json — the content the site reads.
  • index.html — the same content written into the markup, so the page still shows your work with JavaScript disabled and search engines see it without running scripts.

Images: picking a file records its name and dimensions and previews it, but the file itself still has to be copied into the images/ folder and committed. A piece whose image is missing is flagged in red.
