# Material Symbols Importer

A Figma plugin that bulk-imports icons from [Google Material Symbols](https://fonts.google.com/icons)
straight into a Figma file, as components with a document color variable already bound.

It's file-agnostic: on load it scans the current page for every section/frame you could import into
and every color variable (local, plus anything from enabled team libraries) you could apply — nothing
about a specific project is hardcoded, so the same plugin works across files.

## What it does

1. Search Material Symbols by name (4,268 icons, kept up to date — see "Updating the icon list" below).
2. Pick icon settings the same way Google's own icon picker does: **Style** (Outlined / Rounded / Sharp),
   **Weight** (100–700), **Grade** (-25 / 0 / 200), **Fill** (on/off) and **Optical size** (20 / 24 / 40 / 48px).
3. Multi-select any number of icons and bulk-import them in one go.
4. Choose which frame or section in the current page they land in (or use your current selection).
5. Choose a color variable to bind to the icon fill. Variables named like `Icon/Primary` (anything
   containing "icon" + "primary"/"default"/"main") are suggested first and pre-selected.
6. Each icon becomes its own **component**, named from the icon's own name (e.g. `Arrow Back`), with an
   optional prefix you set per import (e.g. `Icon/`).

## Installing in Figma

1. In Figma desktop: **Menu → Plugins → Development → Import plugin from manifest…**
2. Select `figma-plugins/material-symbols-importer/manifest.json` from this repo.
3. Open your file, run the plugin from **Plugins → Development → Material Symbols Importer**.

## Using it

1. Pick a target frame/section at the top (or select one in the canvas before opening the plugin).
2. Set style/weight/grade/fill/optical size.
3. Search and click icons to select them (click again to deselect). Selection count shows at the bottom.
4. Pick a color variable if you want one bound to the icon fill.
5. Optionally set a name prefix.
6. Click **Import N icons**.

## How icon data is fetched

Icon SVGs are fetched live, per selection, from Google's own
[`google/material-design-icons`](https://github.com/google/material-design-icons) GitHub repository —
the canonical source, not a third-party mirror. The plugin's `manifest.json` only allowlists
`raw.githubusercontent.com`.

The icon *name* list (`icon-names.json`) is bundled into the plugin so search works instantly and
offline; it's generated from Google's official codepoints file.

## Updating the icon list

Google adds new Material Symbols icons periodically. To refresh:

```bash
cd figma-plugins/material-symbols-importer
npm run update-icons   # re-downloads icon-names.json from Google's codepoints file
npm run build           # re-inlines it into ui.html
```

Commit the updated `icon-names.json` and `ui.html`.

## Development

- `code.js` — plugin main thread (Figma document/API access, no network).
- `ui.src.html` — UI source (search, settings, network fetches). Edit this file, not `ui.html`.
- `ui.html` — generated by `npm run build`; this is what `manifest.json` actually loads. Don't hand-edit.
- `icon-names.json` — generated icon name list, inlined into `ui.html` at build time.

After editing `ui.src.html`, run `npm run build` before reloading the plugin in Figma.

## Notes / limitations

- Google only publishes static SVGs at fixed axis stops: weight in steps of 100 (100–700), grade at
  -25/0/200, and optical size at 20/24/40/48px. These are exactly the controls exposed here — there's
  no in-between value to fake.
- Binding a library (non-local) color variable requires that library to be enabled in the file
  (Assets panel → the library toggled on) — the same requirement Figma itself has for using library
  variables.
